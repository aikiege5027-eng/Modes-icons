KONE 电梯相关图标 · iconfont / SVG Sprite

收录「最终整理版本」的全部 98 个图标（同一张图只收一次）。class 名是 icon 库原始名称；同一个 class 可能对应多个中文含义，卡片下方列出了全部含义，可以直接搜中文。

方式一：iconfont

引入 CSS，写 class 即可。大小用 font-size，颜色用 color。图标画在 16 网格上，16 / 32 / 48px 这类整数倍最清楚。

<link rel="stylesheet" href="kone-icons.css">

<i class="kone-icon kone-icon-sales" aria-hidden="true"></i>
<i class="kone-icon kone-icon-sales" style="font-size: 32px; color: #1450f5" aria-hidden="true"></i>

方式二：SVG Sprite

保留原始矢量，渲染最精确。把 kone-icons-sprite.svg 和页面放在同一个站点下（file:// 打开时浏览器会拦截跨文件引用），用 <use> 引用；也可以把整个文件内联进页面，再写 href="#class 名"。

<svg width="16" height="16" aria-hidden="true">
  <use href="kone-icons-sprite.svg#kone-icon-sales"/>
</svg>

图标只是装饰时加 aria-hidden="true"；单独承担含义（如只有图标的按钮）时，给外层按钮写 aria-label。
